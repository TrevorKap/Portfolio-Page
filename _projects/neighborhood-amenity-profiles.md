With Anna Duan and Timothy Oliver, I explored Philadelphia's amenity landscape for a Geospatial Data Science in Python class project. We analyzed Yelp API data and Zillow listings to uncover the mix of businesses, public spaces, and activities across Philadelphia neighborhoods, then used k-means cluster analysis to identify six distinct amenity clusters grouping neighborhoods with similar profiles.
